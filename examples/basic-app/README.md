Basic example demonstrating how to use `@tty-pt/scripts` locally.

Run locally

1. From repository root: `pnpm install`
2. Link local package: `pnpm -w install` (or using workspace: the example references `workspace:*`)
3. Start: `cd examples/basic-app && pnpm install && pnpm start`

Build

- `pnpm build` will produce output according to the package configuration.
